# The problem

In my journey into automatic programming, I started out describing the idea of a new project in the usual place: either a README.md or a DESIGN.md or a SPEC.md. However, during the evolution of a project, those kinds of files are constantly written and rewritten by both me and the agent.

Sometimes I found myself pondering whether an idea written in one of those files was truly mine, or was slid in there by an agent. This is not necessarily a bad thing: an idea is an idea and its value should not depend on who had it in the first place. However, I still find it useful to trace things back to the original spark that was there deep inside myself and that pushed me into creating the project. That deliberate act of agency, of bringing something to life, does indeed have a lot of value. Especially now, with the approach of fully automated coding capabilities.

# The core idea

A dedicated file in the spirit of README.md, AGENTS.md or SKILLS.md to capture the original seed of the project. It should contain a sort of brain-dump from the human who conceived the project. Useful things I usually write therein: the original problem that pushed me into creating something new, the core idea, any references to things that inspired the project or one of the desired features, the building blocks that I envision, an initial description of the high-level architecture and things I don't want to compromise on.

Nothing revolutionary, I get it. As with those WHATEVER.md files, I think we can all agree that they are just tokens to be injected into the context window of a model. Pretending they are some sort of standards is honestly laughable.

# INCEPT.md

*An idea is like a virus. Resilient, highly contagious. The smallest seed of an idea can grow. It can grow to define or destroy you. - Dom Cobb, Inception*

The name came to mind because I'm a huge fan of Nolan's movie. I started using it in a couple of projects of mine and the name stuck. I particularly like the analogy between planting the original idea of the project in an AI agent and what Dom Cobb is doing in the movie.

When I saw that the incept.md domain was not already taken, I couldn't resist and I bought it on impulse. I will put a sample INCEPT.md file there. Maybe this very instance of it. Kind of meta, I know.

# A personal blog

Since I have already bought the domain and the usefulness of putting a single MD file there is pretty limited, I will host my personal tech blog there. I really like to rant about technical work with friends and colleagues and I have always toyed around with the idea of writing something.

# An autonomous self-operated crowdfunding platform

Now that the domain is there, I'm starting to have utopia-sized dreams. A person uploads an INCEPT.md document. Backers can put in money using smart contracts that unlock only when a target goal is reached. The money is used to buy tokens to bring the project to reality. Backers could potentially participate in weighted steering rounds if the original inceptor allows for it.
