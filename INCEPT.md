# The problem

In my journey into automatic programming I started out describing the idea of a new project in the usual place. Either a README.md or a DESIGN.md or a SPEC.md however, during the evolution of a project those kind of files are constantly written and re-written by both me and the agent.

Sometimes I found myself pondering whether an idea written in one of those files was truly mine, or was slided in there by an agent. This is not necessarily a bad thing, an idea is an idea and its value should not depend on who had it in the first place. However I still find it useful to trace back things to the original spark that was there deep inside myself and that pushed me into creating the project. That deliberate act of agency of bringing something to life has indeed a lot of value. Especially now, with the approach of fully automated coding capabilities.

# The core idea

A dedicated file in the spirit of README.md, AGENTS.md or SKILLS.md to capture the original seed of the project. It should contain a sort of brain-dump of the human who conceived the project. Useful things I usually write therein: the original problem that pushed me into creating something new, the core idea, any references to things that inspired the project or one of the desired features, the building blocks that I envision, initial description of the high level architecture and things I don't want to compromise on. 

Nothing revolutionary I get it, just as those WHATEVER.md, I think we can all agree that they are just tokens to be injected into the context window of a model. Pretending they are some sort of standards is honestly laughable. 

# INCEPT.md

*An idea is like a virus. Resilient, highly contagious. The smallest seed of an idea can grow. It can grow to define or destroy you. - Dom Cobb, Inception*

The name come to my mind because I'm a huge fan of Nolan's movie. I've started using it in a couple of projects of mine and the name sticked. I particularly like the analogy of planting the original idea of the project in an AI agent and what Dom Cobb is doing in the movie.

When I saw that incept.md domain was not already taken I couldn't resist and I bought it as an impulse. I will put there a sample INCEPT.md file. Maybe this very instance of it. Kind of meta I know.
